Abstract

This paper proposes a memory architecture consisting of four independently addressable peripheral VRAM modules surrounding a central shared memory and controller fabric.

Each peripheral memory module is logically divided into two independently addressable memory regions. These regions may be connected through separate electrical or photonic communication channels, producing up to eight logical memory paths across four physical memory modules.

At the center of the architecture is a Central Memory Fabric Controller (CMFC). Rather than functioning as conventional RAM alone, the CMFC provides multi-channel memory control, buffering, caching, arbitration, aggregation, synchronization, and external data output.

The central research question is whether independently serviced memory domains, combined through a sufficiently wide central aggregation fabric, can provide greater effective memory bandwidth and concurrency than an equivalent architecture in which the same memory resources contend for a smaller number of shared paths.

A later implementation introduces substrate-integrated photonic channels and wavelength-division multiplexing to investigate whether optical communication can improve interconnect density, routing scalability, or energy efficiency.

The fundamental principle is:

Memory parallelism should extend from the physical memory devices through the interconnect and into the controller, rather than collapsing into a serial bottleneck before reaching the processor.

6. Avoiding the Central Bottleneck

This is the central engineering challenge of the POC.

The system should not construct eight high-speed memory channels and then funnel them through one narrow bus.

Instead, the CMFC requires multiple independent internal paths.

For example:

M1 ─────► Queue ───┐
M2 ─────► Queue ───┤
M3 ─────► Queue ───┤
M4 ─────► Queue ───┼──► PARALLEL CROSSBAR
M5 ─────► Queue ───┤           │

                               ▼

The controller should therefore be designed around a crossbar, switched fabric, or comparable parallel topology, not a single serial datapath.

7. Central RAM / Cache

The original center-memory concept remains valuable.

Local high-speed memory inside the CMFC could function as a shared cache or staging area.

The hierarchy becomes:

Peripheral Memory↔Central Shared Memory↔Processor

Frequently shared information could reside centrally.

Domain-specific information remains in peripheral memory.

This reduces unnecessary duplication and cross-domain traffic.

35. Success Criteria

The first-generation POC succeeds if it demonstrates:

four independently addressable memory modules;
split logical domains;
simultaneous memory reads;
simultaneous memory writes;
parallel operation without forced serialization;
correct aggregation of returned data;
measurable scaling as additional domains are activated;
a central controller capable of sustaining a substantial fraction of aggregate peripheral bandwidth.

The photonic extension succeeds if it additionally demonstrates:

simultaneous optical data channels;
reliable wavelength separation;
acceptable BER and crosstalk;
competitive bandwidth density;
measurable power/latency characteristics.
36. What the POC Must Prove

The POC should not attempt to prove that photonic memory is universally faster than conventional VRAM.

It should test three narrower hypotheses.

Hypothesis 1 — Domain Parallelism

Independent memory domains increase aggregate bandwidth when workloads can access them concurrently.

Hypothesis 2 — Parallel Aggregation

A sufficiently wide central fabric can collect multiple memory streams without eliminating the bandwidth gained at the peripheral domains.

Hypothesis 3 — Photonic Scaling

Optical channels can become useful when electrical routing density, distance, fan-out, or aggregate bandwidth makes conventional connections increasingly difficult.

Each hypothesis can be tested independently.

40. Primary POC Thesis

A memory subsystem composed of multiple independently addressable split memory domains can increase aggregate memory concurrency when those domains communicate through a parallel central memory fabric capable of simultaneously scheduling, buffering, aggregating, and forwarding their data. A substrate-integrated photonic interconnect can subsequently be evaluated as a method for scaling those parallel channels without proportionally increasing electrical routing complexity.
